# 更新记录

## 未发布

- MDL 仅显示模型名称，移除活动星号、并发数量及加载、空闲、不可用状态文字；状态及数量通过 STS、ACT 查看。

## 0.3.3

- TPS 从最近 20 条网关请求中选择最新有效测速，保留所属代理、模型及请求时间；缺失数据时悬停说明原因。
- 短样本或疑似集中返回以 `~` 标记估算速度；隐藏思考却缺少思考令牌计数时不计算，避免令牌与时间口径不一致。

## 0.3.2

- 项目名称统一为 `magpie-taskbar`：DLL、压缩包、插件名称和配置文件 `magpie-taskbar.ini` 均采用新名称；旧 `MagpieRoute.ini` 会自动复制，显示项目 ID 保持不变，已有勾选不受影响。升级时请删除 `plugins` 中旧的 `MagpieRoute.dll`。
- 发布包精简为 4 个文件：`magpie-taskbar.dll`、简短安装说明、`LICENSE`、`THIRD_PARTY_NOTICES.md`（内含第三方许可证全文），不再附带第三方源码与开发文档。
- 推送版本标签后由 GitHub Actions 自动构建、测试、打包并发布 Release，附 SHA256 校验文件。

## 0.3.1

- 悬停提示文字与状态报错全面汉化（支持请求阶段、代理、模型、总耗时等中文展示）。
- 明确 TPS/LAT 指标口径（首字延迟缺失显示 `-`，不再回退到总耗时；悬停清晰展示所属历史请求上下文）。
- 网关连接状态不再继承历史失败错误。
- 对齐本地与 CI 构建流程，CI 统一调用 `build.ps1`，`build-mingw.sh` 增加前置自动化测试。

## 0.3.0

- 首次发布，提供 12 个独立显示项、中文项目名称及字符长度配置。
- GitHub Actions 使用 MSVC 构建 x64、Win32，运行路由解析测试。
