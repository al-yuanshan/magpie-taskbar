### 更新内容

- MDL 仅显示模型名称，移除活动星号、并发数量及加载、空闲、不可用等状态文字。
- 无模型数据时显示 `-`；网关状态和活动请求数量仍可通过 STS、ACT 独立查看。

### 下载与安装

- 64 位 TrafficMonitor：`magpie-taskbar-v0.3.4-x64.zip`
- 32 位 TrafficMonitor：`magpie-taskbar-v0.3.4-Win32.zip`
- 退出 TrafficMonitor，替换 `plugins` 内的 `magpie-taskbar.dll` 后重启。
- 安装包包含 DLL、安装说明和许可证，校验值见 `SHA256SUMS.txt`。
