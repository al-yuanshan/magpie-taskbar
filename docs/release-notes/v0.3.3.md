### TPS 测速优化

- 从最近 20 条网关请求中选择最新有效测速，避免缺少计时的请求覆盖有效结果。
- 短样本或疑似集中返回显示估算值，如 `~172.7T/S`，仅表示客户端观测速度，不代表服务端生成速度。
- 隐藏思考但缺少思考令牌计数时不计算，避免令牌与计时口径不一致。
- 悬停分别展示测速所属 agent、模型、请求时间，以及最近请求无法测速的原因。

### 下载与安装

- 64 位 TrafficMonitor：`magpie-taskbar-v0.3.3-x64.zip`
- 32 位 TrafficMonitor：`magpie-taskbar-v0.3.3-Win32.zip`
- 退出 TrafficMonitor，替换 `plugins` 内的 `magpie-taskbar.dll` 后重启。
- 从旧名称版本升级时，请删除旧的 `MagpieRoute.dll`，避免重复加载。
- 安装包包含 DLL、安装说明和许可证；校验值见 `SHA256SUMS.txt`。

TPS 不是实时流式速度；没有有效测量时显示 `-`。发布流程将对两个架构运行 MSVC 构建和解析测试，真实宿主兼容性仍需实际验证。
