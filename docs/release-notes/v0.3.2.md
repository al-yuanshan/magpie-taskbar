### 更新内容

- 项目名称统一为 `magpie-taskbar`：DLL、压缩包、插件名称和配置文件均采用新名称。旧 `MagpieRoute.ini` 会自动复制，已有勾选不受影响；升级时请删除 `plugins` 中旧的 `MagpieRoute.dll`。
- 发布包精简为 4 个文件：`magpie-taskbar.dll`、`README.md`（安装说明）、`LICENSE`、`THIRD_PARTY_NOTICES.md`（含第三方许可证全文）。
- 不再附带第三方源码、开发文档和配置示例；完整说明见仓库。
- 本版本由 GitHub Actions 自动构建、测试并发布，功能与 v0.3.1 一致。

### 安装

- 64 位 TrafficMonitor：下载 `magpie-taskbar-v0.3.2-x64.zip`
- 32 位 TrafficMonitor：下载 `magpie-taskbar-v0.3.2-Win32.zip`
- 退出 TrafficMonitor，将 `magpie-taskbar.dll` 放入 `plugins` 文件夹，重启后勾选需要的显示项目。
- 可用 `SHA256SUMS.txt` 校验下载文件。
